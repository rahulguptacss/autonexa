# Autonexa – Modern, Industrial & Corporate Brand Identity

Autonexa is a high-performance Next.js 16 (React 19, Tailwind CSS v4, GSAP 3.15, Framer Motion) single-page corporate portal for next-generation automotive mobility architectures, robotic cell manufacturing, and advanced engineering solutions.

## Architecture Highlights

- **Framework:** Next.js 16.4.3 (Turbopack) & React 19.3.0
- **Styling:** Tailwind CSS v4 (Electric Cobalt Blue `#0066ff` primary theme)
- **Animations:** GSAP 3.15 ScrollTrigger + Framer Motion interactive gestures
- **Data Source:** Centralized, fully schema-driven architecture powered by `components/data/data.json`
- **Mobile Experience:** Smooth touch-gesture draggable drawer navigation
- **Assets:** High-definition photorealistic WebP assets optimized for web performance

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Build

```bash
npm run build
```
